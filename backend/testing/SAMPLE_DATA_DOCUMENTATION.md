## Data Structure

### Restaurant Schema
```python
{
    "name": str,           # Restaurant name
    "cuisine": str,        # Cuisine type
    "rating": float,       # 0.0 to 5.0
    "image": str,          # Image URL
    "location": {
        "latitude": float,
        "longitude": float,
        "address": str
    },
    "menu": [              # Array of menu items
        {
            "name": str,
            "price": int,  # In Rupees
            "image": str,
            "diet": str,   # "veg", "non-veg"
            "spicy": str,  # "mild", "medium", "hot"
            "nutritional_info": {
                "protein": int,    # grams
                "fiber": int,      # grams
                "calories": int,
                "carbs": int,      # grams
                "fat": int         # grams
            },
            "tags": [str],         # ["modern", "healthy", etc.]
            "is_vegetarian": bool,
            "is_vegan": bool,
            "is_gluten_free": bool
        }
    ]
}
```

## Troubleshooting

### No Food Cards Appearing?
1. Verify database has data: `python testing\verify_data.py`
2. Check backend is running: `http://localhost:8000/foods`
3. Check console logs in React Native app
4. Ensure MongoDB connection is active

### API Returns Empty Results?
1. Re-run population script
2. Check MongoDB URI in `.env`
3. Verify collections exist in MongoDB Atlas

### Need More Data?
Edit `comprehensive_sample_data.py` and add more restaurants/menu items to the `restaurants_data` array.
